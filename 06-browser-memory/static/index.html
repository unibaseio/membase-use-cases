Browser memory

The companion for the Browser Memory side panel. It holds your Membase key on this machine, so the extension never sees it. Ask your memory about the page you are on, or remember the page for later.

Set up the extension

  1. Keep this companion running: uv run 06-browser-memory/app.py.
  2. Open chrome://extensions and switch on Developer mode.
  3. Load unpacked and choose the 06-browser-memory/extension folder. Chrome shows the ID lhojclgfedbhfpkjklfgjgnikckelabe; it is the only origin this companion answers.
  4. Pin the extension and click its icon: the side panel opens beside the page.
  5. On a page, press Remember this page, or type a question and press Ask about this page. Localhost pages work at once; for other sites the panel asks once for permission to read pages.

The extension stores nothing: no key, no answers. Requests from any web page or other extension get 403, and so does any request whose Host is not 127.0.0.1 or localhost.
