How this map was made

Kith has no list of everything you wrote. It asks your memory: your standing facts and latest notes, eight broad questions (“people I work with”, “places I live in or travelled to”…), then one more for every name those turn up. A model names the people, places and things in what comes back and how they connect; anything no note states is left off. Notes your memory never returns for these questions are not on the map.
